# Surface: web stand and widget (playground, kb, widget, settings, embed, lead dialog)

Mode: Operate (playground, settings, widget, embed), Read (kb).
Audience and task: the jury checks the grounding of answers in seconds on a laptop; the client asks a question and hands the request to a manager.
Constraints: shadcn/ui on base-ui, light and dark themes with a switcher (user decision, Nov 2026), the widget on the host site stays light, MTS red only as a signal.

## Direction contract

THESIS: One instrument, not four products. Every screen is the same quiet app frame as the Claude Code desktop app, held to Linear's precision; the answer trace reads like Claude Code's session sidebar. Refuses the per-page personalities (editorial KB, marketing widget hero), cards in panels, and red as decoration.

OWN-WORLD: Neutral graphite ladder (MTS graphite #1D2023 family), surfaces separated by hairlines and one-step tone shifts, no shadows except overlays and the composer. Ink (graphite) primary buttons and switches, as Vercel. MTS red appears only as the mark, the send button and source markers. Geist for all text, Geist Mono only for ids, numbers in data, prompt and JSON. Type steps 11/12/13/14/15/18/24 (10 only for source markers); 11 for mono data and small tags.

STORY: The visitor lands on an empty chat that says what the stand proves, asks, sees quiet numbered sources in the answer, opens the trace on the right and reads it top to bottom: answer, grounding, context budget, search, check.

FIRST VIEWPORT: Left 260px sidebar (mark, New chat with shortcut, Search, sections, Recent, stand status with theme). Center 720px conversation column, 48px bar with title, mode menu and debug toggle. Right ~40% trace panel: stacked sections with 15px headings, label-value rows with right-aligned tabular values, a segmented context bar with a legend, collapsible groups with counts.
