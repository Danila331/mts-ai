# Кэш ответов бейзлайна

`answers.csv` — ответы учебного решения организаторов (`sample_submission/solution.py`) на все
518 вопросов стенда: 18 демо жюри (`demo-<id>`) и 500 кейсов `eval/dataset/cases.jsonl`.

Получены 09.11.2026 на модели `qwen/qwen3.8-27b` через OpenRouter, `MAX_WORKERS=8`, остальные
настройки бейзлайна по умолчанию. Бейзлайн — фиксированная программа, поэтому в CI его ответы не
пересчитываются: это быстрее, дешевле и убирает шум между прогонами.

Пересобрать (нужен ключ в `.env`), если изменится выборка или модель:

```bash
python eval/run_eval.py --set all --baseline --no-judge   # ответы появятся в eval/reports/<время>/baseline/
```
