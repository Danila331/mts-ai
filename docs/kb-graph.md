## Отложенные ребра (проверены, на демо не окупились — откачены 11.11)

Кандидаты: solar → microgeneration (излишки), orem → metering (виды учёта),
tariff → thresholds (670 кВт), askue → metering (минимум ИСУ). Цели чанков
проверены; при расширении сначала мерить A/B на одном судье в одной сессии.

## Поведение по типу ребра

- **ветвление** → назвать обе ветки и когда какая;
- **предусловие** → «для X сначала нужен Y»;
- **дополнение** → «основное + для остальных»;
- **альтернатива** → «если X недоступно, есть Y»;
- **ограничение** → guard-секции всегда в контексте.

## Активация

Ребро включается, только если условие ветки есть в диалоге (ключевые слова). Иначе — нет: контекст не раздуваем.
